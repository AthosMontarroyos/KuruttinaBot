# Roteador de instruções

Este arquivo é somente um ponteiro para agentes de IA. Não contém regras próprias e não deve receber nenhuma.

1. Leia integralmente `.claude/CLAUDE.md` antes de qualquer tarefa; ele é o roteiro único do projeto.
2. Siga a tabela "Seleção obrigatória por contexto" daquele roteiro e leia o `SKILL.md` indicado em `.claude/skills/<skill>/SKILL.md` antes de criar, alterar ou revisar o artefato.
3. Leia as `references/` da skill somente quando o gatilho de leitura da própria skill se aplicar.
4. Procedimentos e aprendizados reutilizáveis devem ser gravados em `.claude/`, nunca aqui.
