# Contribuir

Contribuições são bem-vindas no código licenciado pela GNU AGPL-3.0. Issues e pull requests podem ser escritos em português.

Antes de abrir uma issue, procure se o assunto já existe. Bug e sugestão têm modelos em `.github/ISSUE_TEMPLATE/`. Vulnerabilidade não entra em issue pública: use [SECURITY.md](SECURITY.md).

Não envie token, senha, URL de conexão, ref de projeto, host de pooler nem snowflake de equipe. Não faça deploy. A publicação da instância oficial fica com o autor.

Um pull request entra em `main`. Mudança de comportamento precisa do teste que a cobre, quando o repositório já testa essa área. A referência de comandos locais está em [docs/project/development.md](docs/project/development.md). Este repositório não oferece suporte a instância própria; veja o [README](README.md).

O [código de conduta](CODE_OF_CONDUCT.md) vale para issues, pull requests e os outros espaços do projeto.
