# Segurança

Reporte uma vulnerabilidade em privado pelo [GitHub Private Vulnerability Reporting](https://github.com/AthosMontarroyos/KuruttinaBot/security/advisories/new).

Não abra issue pública, pull request ou discussão com detalhes do problema, prova de conceito, token, senha, URL de conexão ou dado de usuário. Inclua o que for preciso para reproduzir, o impacto e, se existir, um caminho de correção.

O autor responde pelo mesmo canal privado.
