# Base web com React

Status: aprovado pelo responsável pelo projeto em 14 de outubro de 2026.

O website usará React sem Next.js. O objetivo é construir uma base/framework próprio, mantendo liberdade para organizar pastas, roteamento, composição e integração com o servidor conforme as necessidades reais do projeto.

A base implementada usa React, TypeScript, Tailwind, Vite e servidor HTTP Node. Esta decisão substitui as orientações anteriores de Next.js; não exige trocar essas ferramentas nem criar abstrações antes de existirem consumidores.

Procedimentos ficam na [skill do website](../../.agents/skills/website-developer/SKILL.md). Autenticação, autorização, proteção de dados e isolamento entre cliente e servidor continuam requisitos, implementados sem dependência das convenções de Next.js. A decisão de hospedagem permanece separada.
